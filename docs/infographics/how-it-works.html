How it finds a run

From a process to a live log, without touching the run

1

Spot the process

Scans the process list for Claude Code, however it was installed or started.

nativenpmclaude.exe
2

Match its session

Reads the session file Claude Code keeps for each running process.

~/.claude/sessions/<pid>.json
3

Follow the log

Tails the transcript: prompt, messages, tool calls and results, as they happen.

~/.claude/projects/…/<session>.jsonl
4

Name where it came from

Hermes tags the processes it starts; otherwise the parent process tells.
